All examples below are hypothetical defensive applications. Original register mechanisms and rights risks are preserved as source material, not independently established findings. Source-check depth is recorded in the accompanying ledger; a linked paper is not automatically an evaluated instance of the policy.

**H:** human component studies. **T:** technical component studies. **O:** observed implementation or quasi-experimental component. **A:** adjacent evidence. **N:** normative, design or measurement basis.

## I-001 · Root-purpose provenance across multi-agent handoffs

**Evidence basis:** N · Design only; technical analogy. **Legacy group:** E.
**Recommendation:** Pilot purpose-bound delegation.

A signed purpose can make delegation inspectable, but it cannot establish that the declared purpose is legitimate or that downstream actions preserve agency.

**Hypothetical application:** A public assistant records the authorised task before delegating a document search.
**Evidence needed next:** Test false declarations, unauthorised scope changes, and whether an independent reviewer can stop the whole workflow.

**Original actor / mechanism:** Agent providers, deployers, auditors, public procurers. Bind every delegated subtask, tool call, generated artifact, and terminal action to a signed root-purpose record, with explicit scope changes and controller identity.
**Original causal node / agency domain:** Capability → controller → delegated vector. Executive; decisional; collective / institutional.
**Original rights and trade-offs:** Minimize retained content, separate oversight metadata from message content, and provide due process for contested classifications.
