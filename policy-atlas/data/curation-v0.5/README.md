# Stable-core selection overlay

This directory does not replace the evidence corrections in
`data/curation-v0.4/`. It adds the frozen
`stable-core-selection-v0.1` workload for release v0.2.0-beta.1.

The selection is a **retrospective, non-preregistered, project-authored
editorial prioritisation** derived after inspecting v0.1.0-beta.2. It changes
no source claim, evidence status, legal status, or effect classification. The
30 included rows have a ledger; the other 88 candidates do not yet have
independently double-coded row-level exclusion rationales, so this overlay is
not a reproducible systematic-screening result. All 30 rows remain
`proposed_core_candidate` and not rank-eligible. The rule, declared process,
actionability skew, and limitations are in
`protocol/STABLE_CORE_SELECTION.md`.
