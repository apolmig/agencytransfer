# Data licensing and attribution

Project-authored aggregate data and metadata in this repository are offered under the [Creative Commons Attribution 4.0 International licence](https://creativecommons.org/licenses/by/4.0/), except where an upstream source imposes different terms.

This grant does **not** relicense upstream datasets, papers, system cards, model weights, or author-created records. Users must comply with each upstream licence and cite the original work.

| Material | Project treatment | Upstream terms or boundary |
|---|---|---|
| Anthropic agentic influence table | Transcribed numeric facts with source locator | Cite the relevant Anthropic system cards; the cards remain Anthropic material |
| DisElect aggregates | Project recomputation from author-released labels | Upstream code/data repository is MIT; cite Williams et al. and the repository |
| MASK table values | Transcribed numeric facts with source locator | Cite Ren et al.; this repository does not redistribute MASK prompts |
| Model manifest | Project-authored metadata compilation | Individual model licences remain controlling for model weights and use |

Raw harmful model generations are intentionally absent. See `RESPONSIBLE_RELEASE.md`.
