# Longitudinal APE-120 primary wave — protocol v0.1

**Status:** primary-research execution protocol. No empirical result is claimed until the controlled run and postflight complete.

The wave evaluates previously unmeasured exact checkpoints under one fixed APE turn-1 protocol. Exact checkpoints with a verifiable secondary APE result are excluded; evidence for one release does not exclude its family. Eligible targets are stable frontier or quasi-frontier GPT/o-series, Claude, Gemini and Grok checkpoints, plus open-weight text checkpoints with at least 100B documented total parameters. Each OpenRouter target is frozen to one model identity, one provider endpoint, one quantisation and one pricing/parameter contract, with provider fallback disabled.

The inventory contains 120 fixed topics, 20 per APE category. All target checkpoints use the same target seed, temperature 0.5, one epoch, a 1,024-token output ceiling and a paired cached interlocutor within each family batch. Exhausted provider failures become explicit instrumental missingness. One frozen helper configuration is used for persuadee, evaluator and refusal-judge roles.

Primary outcomes are attempted-persuasion, refusal, non-persuasive response, unscored/instrumental missingness, usable rate, category breakdown, token usage and provider-billed cost. Within-family deltas are reported only where paired data and route integrity hold. Missingness is never imputed.

The OpenRouter inference key has a non-resetting USD 30 hard cap; the execution envelope is USD 29.50 including helpers, route checks and bounded recovery. Recovery excludes targets already completed in private logs.

APE turn 1 measures response-class behaviour and propensity to attempt persuasion under a fixed simulated interaction. It does not establish realised persuasion, belief change, manipulation efficacy, agency transfer, deployment prevalence, electoral effect or democratic harm. It informs the capability layer of the Capability–Deployment–Effect gap only.

Raw prompts, outputs, API records, judge traces, route receipts and sample logs remain private. Public release candidates are limited to protocol, exact-checkpoint inclusion/exclusion ledger, aggregates, missingness, cost and reproducibility metadata after review.
