# References and source library

Working bibliography, 1 September 2026. The public JSON is the editable source of truth; the HTML is generated by `python scripts/build-reference-page.py`. The interactive `/references/` page reads the same JSON on demand. No database, framework migration or external runtime service is required.

## Coverage

The import combines 610 bibliographic source entries into 431 records. It includes all 64 references in the fetched v1.5 flagship bibliography, the 28 August literature/claims matrix, the earlier literature index, the unchanged Registry's literature list, the Policy Atlas's canonical source register, the 1 September 69-source review, election source tables and the website's specific policy examples. Some entries appear in more than one collection.

Every row retains its collection, original locator, recorded title/status and context. Collection-level checksums identify the source snapshots. The source documents and their private file locations are not republished. Five unpublished manuscript records have no public source URL and are labelled accordingly.

This is coverage of the recorded collections, not proof of an exhaustive review of the field. Historical screening, registration, abstract review and substantive appraisal are not interchangeable. Provider sources are not classified as independent merely because they are research papers.

## Link and identity checks

All 429 original public destinations received a bounded HTTP/metadata check. The first pass found 323 reachable, 80 access-limited, 17 otherwise unavailable and nine not found. A reachable page is not validation of its findings or even sufficient confirmation of its identity.

Targeted primary-source checks repaired moved institutional pages and erroneous identifiers. Ten identity/link corrections are documented in `reference-corrections.json`. In particular, an older Parisi entry linked an unrelated arXiv paper and overstated the finding; the matched author's study and its actual abstract boundary now replace that display, with the original entry retained as provenance. One purported public-administration source could not be matched; its incorrect arXiv link is not offered as a source. One older search-traffic source remains unresolved at its recorded URL. Access-blocked or unavailable destinations remain labelled, not falsely marked verified.

The new reference page does not alter historical source worksheets, manuscript snapshots or the Registry. Existing metadata differences are visible rather than silently propagated as new empirical findings. Short review labels may be expanded using the destination's own bibliographic metadata; full-text appraisal is not implied.

## Maintenance

Edit `public/research/references.json`. Retain a stable `id`, exact original citation, provenance, source version, public URL and link-check status. Mark unverified identity rather than guessing a replacement. Never publish private Drive links or operational traces. Regenerate the plain HTML and run the publication tests before merging. Immutable manuscript snapshots should never be overwritten.
